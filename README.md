# GROUND CUP — PUBG 대회 사이트 V1.3

## 구성
- `index.html` : 전체 페이지 (가독성 높은 Gothic A1 폰트 적용)
- `style.css` : 스타일 및 관리자 전용 UI / 반응형 디자인
- `script.js` : 참가 승인/거절 시스템, 참가팀 삭제, 실시간 순위표 편집

## V1.3 신규 기능 및 수정 내용
1. **한글/영문 폰트 가독성 최적화**
   - 얇고 깔끔한 Gothic A1 폰트로 변경하여 글자가 안 보이는 현상 해결
2. **참가 팀 신청 승인/거절 시스템**
   - 일반 신청 시 승인 대기열로 접수
   - 관리자가 확인 후 승인해야만 open slot에 참가 팀으로 등록됨
3. **참가 팀 관리자 삭제 기능**
   - 잘못 올라가거나 삭제가 필요한 팀을 관리자 권한으로 삭제
4. **실시간 순위표 수정 및 저장**
   - 관리자 로그인 시 순위표 테이블을 즉시 편집(셀 클릭) 가능
   - 행 추가/삭제 및 [순위표 저장] 지원

## 사용법
- 관리자 로그인: 화면 왼쪽 아래 **`🔒 관리자 로그인`** 클릭 -> 비밀번호 입력 (**기본: `1234`**)
- 압축을 해제한 후 `index.html`을 브라우저로 실행하거나 GitHub Pages에 바로 올리시면 됩니다.
